# PRD: YouTube 썸네일 생성기

## 목표
유튜버가 썸네일 제작의 번거로움 없이, 프롬프트(+선택 이미지)만으로 클릭을 부르는 16:9 썸네일을 빠르게 만든다.

## 사용자
유튜브 채널을 운영하는 사람. 디자인 도구에 익숙하지 않아도 영상 내용 설명만으로 퀄리티 있는 썸네일을 얻고 싶어 한다. 목적은 더 쉽고 빠른 썸네일 제작으로 영상 유입(클릭률)을 높이는 것.

## 핵심 기능
1. **프롬프트 기반 생성(필수)** — 텍스트 프롬프트로 `gpt-image-2`를 호출해 1280×720 썸네일 후보 **3장**을 만든다.
2. **선택 이미지 반영(선택)** — 배경/로고/사진 등 **0~4장**을 업로드하면 `images.edit`로 반영한다. 없으면 `images.generate`.
3. **후보 선택** — 3장 중 1장을 고른다.
4. **제목 오버레이(선택)** — 큰 제목 텍스트를 **클라이언트 canvas**로 얹는다(AI가 글자를 그리지 않아 철자 100% 정확, 비용 없이 즉시 반영).
5. **PNG 다운로드** — 선택본 + 오버레이를 1280×720 PNG로 내려받는다.

## UX 수용 기준
- **상태 머신**: `idle → generating → (success | error)`. 어떤 경로에서도 사용자가 입력한 프롬프트·제목·이미지를 보존한다(에러/취소 포함).
- **로딩**: 생성은 n=3·medium 기준 실측 ~40~70초(변동 큼) 걸릴 수 있다. 후보 자리 3개 스켈레톤 + 경과 타이머 + 취소 버튼을 제공한다. 서버 타임아웃은 이를 넉넉히 넘겨 잡는다(정상 생성이 끊기지 않도록).
- **입력 검증**: 프롬프트 빈값이면 생성 버튼 비활성. 이미지는 비이미지/8MB 초과/4장 초과를 제출 전 인라인으로 거부하고, route에서 재검증한다.
- **에러**: 4개 코드(`INVALID_INPUT`, `CONTENT_POLICY`, `RATE_LIMITED`, `UPSTREAM_ERROR`)별 한국어 메시지와 다음 행동(수정 유도/재시도)을 보여준다. `retryable`이면 1탭 재시도.
- **제목 편집**: 제목 텍스트를 바꾸면 API 재호출 없이 미리보기가 즉시 갱신된다.
- **접근성/반응형**: 키보드 포커스, 후보 `alt`, 로딩 `aria-live`, 모바일 1열 / 데스크탑 후보 1~3열.

## MVP 제외 사항
- 로그인/계정, 생성 기록·갤러리 저장, 결제/크레딧 관리
- 스타일 프리셋(게임/브이로그 등)
- 제목 오버레이의 위치/색 커스터마이즈 컨트롤 (하단 스크림+외곽선 고정 스타일로 시작)
- 배포(로컬 개발 `npm run dev` 기준)
